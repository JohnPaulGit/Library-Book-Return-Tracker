# IT20 Midterm: Library Book Return Tracker

## Overview
This Java desktop app manages library book returns. We used a Stack (LIFO) built with a custom Singly Linked List because librarians process the most recently returned books from the top of the pile first. No `java.util` collections were used. 

## Features
* **Add Book (Push):** Adds a book ID and title to the top of the stack.
* **Process Return (Pop):** Removes and displays the most recent book.
* **View Stack:** Displays the current list of returned books waiting to be processed.
* **Search:** Uses a manual linear search to find a specific book by its ID.

## Setup
1. Clone the repo: `https://github.com/JohnPaulGit/Library-Book-Return-Tracker.git`
2. Open the project in Apache NetBeans.
3. Run `LibraryTrackerUI.java` (Shift+F6).
